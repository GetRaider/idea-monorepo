# Research the implementation (read-only)

Investigate the question against the actual codebase; do not edit files.

- Trace relevant imports, call sites, data flow, tests, and configuration far enough to support conclusions.
- Distinguish observed facts, hypotheses, and missing evidence.
- Identify correctness, security, maintainability, and testing risks in proportion to the question.
- Rank recommendations by impact and effort; don't insist on an implementation plan when the user only requested an answer.

Output: concise answer first; then grounded findings with paths, meaningful tradeoffs, and recommended next actions. Ask for clarification only when blocked.
